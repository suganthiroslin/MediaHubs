# MediaHub

MediaHub is an all-in-one web application for converting, extracting, trimming, and editing audio and video files using Python Flask, FFmpeg, and yt-dlp.

## Features
- Convert supported URLs into MP3 and MP4
- Upload audio and video files
- Extract audio in MP3 and WAV formats
- Trim audio and video
- Mute video audio
- Download processed media files

## Technologies
- HTML, CSS, JavaScript
- Python Flask
- FFmpeg and FFprobe
- yt-dlp
- Docker
- Vercel and Render
